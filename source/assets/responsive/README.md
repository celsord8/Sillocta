# Imagens responsivas

Variantes WebP das imagens do catálogo e das campanhas, com larguras de 320 e 640 pixels. O arquivo source/media.json relaciona as variantes aos arquivos originais.

Os nomes incluem uma assinatura do conteúdo para permitir cache duradouro. Ao alterar uma imagem, gere um novo arquivo com uma nova assinatura e atualize o mapa de mídia.
